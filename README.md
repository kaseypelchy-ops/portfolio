# Kasey Pelchy Portfolio

A Next.js portfolio centered on reusable business-system patterns rather than company-specific implementations.

## Case-study framing

Each project is presented in two layers:

1. **Reusable business pattern** — the operational problem, business value, and industries or workflows where the architecture can apply.
2. **Built example** — the public-safe implementation, technical approach, interactive reconstruction, stack, and GitHub showcase.

The goal is to make the work understandable to employers and prospective Cwlwm Systems clients outside the industry where a system was originally built.

## Cwlwm Systems

Cwlwm Systems is the independent company behind the business-facing services. Portfolio links point to the live company website at https://cwlwmsystems.vercel.app.
